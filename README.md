# Fashion and City
## About the project
Fashion and City is a clothing website created for a wed development project.
The website shows different clothing items and gives users information about the brand

## Project Goals
The goals of this project is to create a simple and attractive website that is easy for users to use. The website is also made to work on computers, tablets and mobile phones.

##  Website features
Home page
About Us page
Product page
Enquiry page
Responsive design
Navigation
Images and links
Responsive design for phones and tablets
