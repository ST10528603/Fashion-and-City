# FASHION AND CITY
### WEDE5020 – Website Development Project

## 1. Introduction

Fashion and City is a fictional online clothing store that I created for my WEDE5020 website development project. The main purpose of the website is to give customers an easy way to explore different fashion styles and clothing categories.

The website includes fashion for women, men and teenagers, as well as shoes, bags and accessories. I chose a pink and white colour theme to give the website a fashionable and welcoming appearance.

## 2. Project Objectives

The main objectives of Fashion and City are:

- To create a website that is attractive and easy to use.
- To display different clothing and fashion products.
- To make it easy for visitors to move between website pages.
- To provide contact and enquiry options for customers.
- To make the website suitable for computers, tablets and mobile phones.
- To use SEO techniques to help improve the website's visibility online.

## 3. Website Pages

The Fashion and City website consists of five main pages.

| Page | Description |
|---|---|
| Home | Introduces the clothing store and displays the main categories and promotions. |
| Products | Displays the different fashion categories and products available. |
| About Us | Provides information about Fashion and City, including its purpose and target audience. |
| Enquiry | Allows visitors to send questions about products and services. |
| Contact | Provides visitors with a way to contact the company. |

## 4. Technologies Used

The following technologies and tools were used to develop the website:

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to add colours, layouts, styling and responsive design.
- **JavaScript:** Used to add interactive features to the website.
- **Visual Studio Code:** Used to write and edit the website code.
- **GitHub:** Used to store project files and keep track of changes made to the website.

## 5. Website Features

Fashion and City is designed to give visitors a simple shopping experience. The website includes:

- A homepage with a fashion banner.
- Navigation links to the different website pages.
- Different clothing and accessory categories.
- Product images and prices.
- A search section for finding products.
- A wishlist and shopping bag.
- An image lightbox for viewing product pictures.
- Contact and enquiry forms.
- Social media links.
- A responsive layout for different screen sizes.

## 6. Search Engine Optimisation (SEO)

SEO was included in the Fashion and City project to help search engines understand the website and make its pages easier for people to discover. Google Search Central (n.d.) explains that useful website content, clear page titles and descriptive image text can help search engines understand a website.

### 6.1 On-Page SEO

On-page SEO focuses on the content and elements found directly on the website. The following techniques were included:

- Adding page titles to the different HTML pages.
- Adding meta descriptions to explain what each page is about.
- Using relevant keywords related to fashion and clothing.
- Using headings to organise the website content.
- Adding alternative text (alt text) to images.
- Adding internal links to help visitors move between pages.

Google Search Central (n.d.) recommends using clear page titles, useful descriptions and descriptive alternative text for images.

### 6.2 Off-Page SEO

Off-page SEO focuses on activities that take place outside the website to help improve its online presence.

For Fashion and City, the following strategies were considered:

- Promoting the clothing store on Instagram, TikTok and Facebook.
- Working with fashion influencers to introduce the brand to more people.
- Getting links from other relevant fashion websites.
- Encouraging customers to leave reviews.
- Promoting the brand to potential customers in Johannesburg, South Africa.

These strategies can help Fashion and City reach more people and build awareness of the brand.

### 6.3 Technical SEO

Technical SEO focuses on making the website easier for search engines to access and understand.

Two technical files were created for the project:

**robots.txt**

The robots.txt file provides instructions to search engine crawlers about which parts of a website they may access. Google Search Central (n.d.) explains that this file helps manage crawler access, but it does not guarantee that a page will be removed from Google Search.

**sitemap.xml**

The sitemap.xml file contains a list of the main pages on the website. It helps search engines discover the website's pages. According to Sitemaps.org (n.d.), an XML sitemap uses tags such as `<urlset>`, `<url>` and `<loc>` to list website addresses.

## 7. Responsive Design

The website was designed to work on different screen sizes, including desktop computers, tablets and mobile phones. CSS media queries are used to adjust the layout depending on the screen size.

This is important because visitors should be able to view and use the website without struggling with the layout on smaller devices.

The website was developed using Visual Studio Code. It can be prepared for publishing through a web hosting platform once the development and testing stages are complete.

After the website has been published, its actual web address can be added to the sitemap.xml file. The sitemap can then be submitted through Google Search Console.
